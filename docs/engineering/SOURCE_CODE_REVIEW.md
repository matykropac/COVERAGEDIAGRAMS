## Critical code-path review

1. Config.validate checks parameters, k factor, distance limits and reference; PAR sample count differs from actual axes sector.
2. axes builds polar grids: PAR ±15° about bearing; PSR/SSR 360°.
3. ParScanPattern holds source 3D gain matrix. TRACKING scans boresight slice with assumed steering loss. FIXED_3D bilinearly interpolates full static pattern. Albersheim is an assumed illustrative Pd/Pfa model, not measured radar performance.
4. solve computes cumulative radial apparent-angle horizon on effective Earth, geometric upper/lower limits and antenna-dependent visibility. Missing terrain stays unknown.
5. apply_obstacles changes horizon and visibility. Cached recomputation must always restart from terrain; prior masked status cannot be reused.
6. status_at_height turns AGL into terrain + target height and applies the pattern again. Coordinate and reference integrity is mandatory.
7. airport_runways geodesically projects thresholds and midpoint using unverified OurAirports endpoints; outputs TRUE bearing.
8. fetch_airspaces queries OpenAIP Core API with bounded count, checks polygon topology, keeps vertical reference text. HTTP 403 means restricted service, not an empty CTR.
9. fetch_osm queries bounded Overpass neighborhood and parses footprints. Point towers receive visualization-only small squares.
10. position_layers_export_dialog creates standalone KML/KMZ/GeoJSON WITHOUT a radar result. Multiple layers and source metadata survive; physical volume is not exported.
11. exports_dialog and coverage_report produce computed-only PDF 600 DPI, PNG, QuickReport and ZIP. Correct UI distinction now restored.
12. project_file saves computed matrices and metadata; on load the workspace reinstantiates antenna models.
